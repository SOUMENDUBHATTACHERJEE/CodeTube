# 📚 CodeVault — Your Coding Resource Hub

Welcome to **CodeVault**, a student-friendly website designed to provide easy access to curated resources for learning and mastering various programming languages. Whether you're just getting started or looking to deepen your knowledge, CodeVault connects you with tutorials, documentation, tools, and practice platforms — all in one place.

## 🌐 Features

- 🎯 Choose your favorite programming language (e.g., Python, JavaScript, C++, Java, etc.)
- 📘 Access categorized resources: tutorials, documentation, videos, and practice sites
- 🔎 Simple, intuitive interface designed for student use
- 🌙 Dark mode support (optional)
- 📱 Fully responsive design
